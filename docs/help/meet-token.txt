Usage: meet token --room <room-name> [options]

Generate a moderator access link for a meeting room.

A token is a signed 8x8/JaaS JWT embedded in the printed meeting URL. Opening
that URL joins the room as a moderator, enables recording controls, and bypasses
the room's registered time window. Send the plain room URL to guests; keep the
token URL for the moderator.

Requires 8x8-keys (app-id, key-id, private-key) in the config.

Example:
  meet token --room workshop-april
  meet token --room demo --config config/defaults.yaml,config/host.yaml,secrets/host.yaml
  meet token --room demo --name Admin --expiry 4h

Options:
  --room <name>       Room name to generate the moderator link for. Required.
  --config <paths>    Comma-separated config files. Defaults to auto-discovery
                      from CONFIG_PATH, SECRETS_PATH, and local config files.
  --name <name>       Moderator display name. Defaults to configured
                      default-moderator-name or "Moderator".
  --expiry <duration> Token validity duration, such as 2h or 30m. Default: 2h.
