Usage: meet <command> [options]

Commands:
  serve    Start the web server (default)
  token    Generate a moderator access link for a room
  moderator-link
           Generate or send a room-scoped moderator magic link
  moderator-verify
           Verify a room-scoped moderator magic link and print the moderator URL
  create   Register a meeting room with a start/end window
  cancel   Cancel a registered meeting room
  list     List registered meeting rooms

Flags:
  --help          Show this help
  --version       Print version and exit

Run 'meet <command> --help' for command-specific help.

See also: meet-helper (SSH wrapper for invoking any meet subcommand on a remote host)
