Usage: meet-helper <host> <subcommand> [args...]

Invoke any meet subcommand on a remote deploy host via SSH. The config
cascade (defaults.yaml + per-host config + secrets) is supplied
automatically using the deploy convention.

Examples:
  meet-helper light-hugger token --room workshop-april
  meet-helper light-hugger create --room demo \
    --from 2026-05-25T19:00:00Z --until 2026-05-25T21:00:00Z
  meet-helper light-hugger list --filter active
  meet-helper light-hugger cancel --room demo

The host must have meet deployed at /srv/meet/meet with config and
secrets at the standard paths.

Help for a specific remote subcommand: meet-helper <host> <subcommand> -h
(the -h is forwarded to the remote meet binary).
